Using Google Forms as Your Data Source

Have teachers submit activity details via a Google Form. The responses link to a Google Sheet which you can export as CSV and upload here.

1

Create a Google Form with these fields

Add the following questions: Class, Student Name, Activity Name, Teacher In-Charge, Venue, Day & Time. Share the form link with all teachers.

2

Link to a Google Sheet

In your Google Form, click Responses → Link to Sheets. All teacher submissions will automatically appear in the spreadsheet.

3

Export the Sheet as CSV

In Google Sheets, go to File → Download → Comma Separated Values (.csv). Save the file to your computer.

4

Upload to this system

Go to the Excel / CSV Upload tab and upload the downloaded CSV file. Ensure the column headers match: Class, Student Name, Activity Name, Teacher In-Charge, Venue, Day & Time.

5

Refresh data each term

Repeat steps 3–4 at the start of each term. Use Clear All Records in Manage Activities first to avoid duplicates, then re-upload the fresh export.

Paste CSV Data Directly

Copy data from your spreadsheet and paste it here. First row must be the header row with column names.
